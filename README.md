# Lumveil ver. 2.1.0

MPVベースの動画プレイヤー。自動画質調整・フレーム補間・GPUシェーダー設定を搭載。

**制作:** ふぁん

---

## 特徴

### Lumveil Native ダークGUI（ver.2.0で刷新）
動画を主役にするため、アプリ内ヘッダーをなくし、動画面をクライアント領域いっぱいに配置しました。操作ドックはv1.8と同じく通常時は下部に固定し、全画面時だけマウスを画面下端へ移動すると一時表示します。補助機能はメイン画面の右クリックにある「その他の操作」サブメニューへ集約しました。Windows 10 / 11に自然になじむダークタイトルバーと統一アイコンを採用し、再生操作・視聴情報・補助操作をまとまりごとに整理しています。AUTOは現在の状態が分かるチップ表示になり、プリセットやON/OFFは文字色だけでなく背景付きの選択状態で確認できます。動画面は黒のまま保ち、奇抜さを抑えた一体感のある外観です。

設定画面は5タブと高度なGPU・シェーダー機能を維持したまま、見出しとカード面で内容を整理しました。操作バーの「画質」からは、用途別プリセット4種、AUTOのOFF＋4段階、詳細設定への導線をまとめた移動可能なクイックパネルを開けます。

### 音量表示（ver.2.0で改善）
動画上でマウスホイールを操作すると、従来の音量ボタンと同じ縦型ボリュームバーを表示し、現在値を確認しながら調整できます。ホイール操作で表示したバーは操作停止後に自動的に閉じます。

### About・更新確認（ver.2.0で追加）
設定の「アプリ情報」タブからアプリ名、バージョン、作者、GitHub、第三者ライセンスを確認できます。GitHub Releasesの手動確認と自動確認ON/OFF、新しいインストーラーのダウンロード・起動に対応します。インストールは必ずユーザーの確認後に開始します。

### フレーム補間（デフォルトON）
30fpsの動画を60fps相当に補間し、なめらかに再生します。多くの動画プレイヤー（VLC等）では搭載していない機能で、特に映画やアニメで違いを実感できます。再生速度を変更した際（0.75x・1.25x等）のカクカク感も同時に軽減します。

### 自動画質調整（ver.1.7で刷新）
暗いシーンを検出し、暗部だけを持ち上げる「シャドウリフト」で見やすくします（中間調・ハイライトは保護されるため画面全体が白っぽくなりません）。強度は操作バーのAUTO状態チップまたは画質クイックパネルから「控えめ／標準／見やすさ優先／極暗」の4段階＋OFFを選択でき、意図的な暗転・ホラー演出は自動的に補正を弱めます。黒つぶれが激しい動画向けの「極暗」モードでは、輝度・コントラストも大きめに補正します。

### 映像モード
標準・シネマ・ダイナミック・鮮やか、TVのような映像プリセットをワンクリックで切り替えられます。

### 用途別画質プリセット
設定画面から「軽快」「標準」「アニメ高画質」「暗所優先」を選べます。画質・負荷・暗所補正の使いやすさをまとめて切り替えられ、詳細設定を知らなくても用途に合わせられます。利用者が追加した外部GLSLシェーダーは保持されます。

### Anime4Kプリセット
公式推奨の組み合わせ（モードA/B/C・軽量）をワンクリックで適用。ファイルを個別に選ぶ必要はありません。

### 字幕・音声トラック / スクリーンショット / ブックマーク / 履歴
複数トラックの切替、外部字幕の追加、静止画保存、任意位置のブックマーク、直近10件の再生履歴に対応。

### GPUシェーダー設定
スケール・クロマスケール・デバンディング・アンチリンギング・ディザリング・トーンマッピング・デインターレース等、映像品質に影響するGPU設定をGUI上で変更・保存できます。

### 全画面時の操作バー自動表示
全画面表示中は操作バーを非表示にし、映像を画面いっぱいに使います。マウスを画面下端に近づけるか右クリックすると一時的に表示されます。

### 続きから再生（ver.1.4で追加）
動画を閉じた位置を自動記憶し、次回同じファイルを開いたときに続きから再生します（先頭・末尾付近は対象外）。

### 連続再生・プレイリスト（ver.1.4で追加）
動画を1本開くと同じフォルダ内の動画が自動でプレイリスト化され、再生が終わると次のファイルへ自動的に進みます。複数ファイルをまとめてドラッグ＆ドロップした場合はその順番で再生します。

### 再生リストの表示
☷ボタンから現在の再生順を確認できます。再生したい動画を選ぶと、その動画へすぐ移動できます。

### A-Bリピート（ver.1.4で追加）
区間を指定してループ再生できます。ダンス・演出など繰り返し確認したい場面に便利です。

### 常に手前に表示（ver.1.4で追加）
他の作業をしながら「ながら見」したいときに、ウィンドウを常に最前面に固定できます。

### 字幕・音声の同期／見た目調整（ver.1.4で追加）
字幕の表示タイミング・サイズ、音声の再生タイミングをスライダーで細かく調整できます（Bluetoothイヤホン等での音ズレ補正にも）。

### AMD AMF補間（ver.1.5で追加）
AMD GPU内蔵の専用ハードウェアで、動きを解析して本物の中間フレームを生成します（フレームレートを約2倍に）。通常のフレーム補間より高品質ですが、AMD GPU + GPU再生支援（オン）が必要です。非対応環境や高フレームレート素材では自動的にスキップされ、通常のフレーム補間と同時使用はできません（排他制御）。

### 操作バーのカスタマイズ（ver.1.5で追加）
「設定 → 詳細 → 操作バー」で、`画質`を含む常時表示ボタンをON/OFFしたり、ドラッグで並び順を変更できます。補助機能はメイン画面の右クリックメニューにある「その他の操作」サブメニューから利用できます。

### 音量・再生速度のUI刷新（ver.1.5で追加）
音量ボタンをクリックすると縦型スライダーがポップアップ表示されます（右クリックでミュート）。再生速度は数値ボタンをクリックして一覧から選ぶ方式です。時間表示はシークバー左右の経過時間・総時間へ集約しています。

### 分かりやすい設定画面
設定は「かんたん／画質／再生と字幕／詳細／アプリ情報」の5つに整理され、各セクションをカード面で見分けやすくしています。普段は「かんたん」から用途別プリセットと暗闇補正を選ぶだけで使え、GPU・シェーダー・操作バーの調整は必要なときだけ「詳細設定」の折りたたみ項目を開けます。

### 再生終了時・再開・並び順の設定（ver.1.5で追加）
「設定 → 再生と字幕」タブで、再生終了時の動作（停止／次の動画を再生／リピート）、前回位置からの再開有無、フォルダ末尾での動作（停止／先頭へ戻る）、連続再生時の並び順（ファイル名順／更新日時順）を選べます。「リピート」は現在の動画を先頭から繰り返し、次の動画へ進みません。

### 設定の自動保存
音量・手動画質・GPU設定・字幕／音声の同期・ブックマーク・履歴・保存先・再開位置を保存します。手動画質は終了時に保存し、「再生と字幕 → 起動時に手動画質を復元」で起動時の復元を切り替えられます。AUTO稼働中も保存するのは元の手動調整値で、AUTO自体は起動時に開始しません。

## 起動方法

`Lumveil_v2.1.0_Setup.exe` を実行してください。既定のインストール先は `C:\Program Files\Lumveil` です。

### インストール時のWindows警告について（v2.1）

現在のv2.1インストーラーは**コード署名を付けていません**。ダウンロード後の初回起動時に、Microsoft Defender SmartScreenの「WindowsによってPCが保護されました」が表示される場合があります。未署名・配布実績が少ないファイルに対する警告であり、この表示だけでウイルスが検出されたことを意味するものではありません。別のPCや次のバージョンでも表示される場合があります。

1. [公式GitHub Releasesのv2.1.0ページ](https://github.com/dhinsk65-create/Lumveil/releases/tag/v2.1.0)から、`Lumveil_v2.1.0_Setup.exe`と`SHA256SUMS.txt`を入手してください。
2. PowerShellで`Get-FileHash -LiteralPath .\Lumveil_v2.1.0_Setup.exe -Algorithm SHA256`を実行し、結果が同じリリースの`SHA256SUMS.txt`と一致することを確認してください。ハッシュ照合により、ダウンロードしたファイルが公式の配布ファイルと同一であることを確認できます。
3. 配布元とファイルの一致を確認し、実行を信頼できると判断した場合に限り、警告画面の「詳細情報」→「実行」から進められます。不明な配布元・ハッシュ不一致・別のウイルス検出警告がある場合は実行しないでください。

SmartScreenやウイルス対策を無効化する必要はありません。詳細は[MicrosoftのSmartScreen説明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)を参照してください。

## ファイル関連付け

動画ファイルをダブルクリックしたときにLumveil で開くよう設定できます。

1. `Lumveil_Associate.exe` をダブルクリック
2. 「このアプリがデバイスに変更を加えることを許可しますか？」→ **はい**
3. 関連付けたい拡張子にチェックを入れて「関連付ける」をクリック
4. 動画ファイルをダブルクリック →「アプリを選択」画面で **Lumveil.exe** を選び **「常に使う」** をクリック

> Windowsの仕様により、最終的な既定アプリの選択はユーザー操作が必要です。関連付けツールを実行することで選択候補の一覧にLumveil が表示されるようになります。
> 関連付けは一度設定すれば以降は不要です。解除したい場合は同じツールから「選択を解除」をクリックしてください。
> アンインストール時も、現在のユーザーについて、このインストール先を指す関連付けを解除します。保存されている以前の関連付けは復元し、別のアプリや別のインストール先を指す設定は保持します。解除に失敗した場合はファイルを削除せず中断します。

## 追加の操作・表示

- **指定時刻へ移動**: `J` または動画面の右クリックから開き、秒数・`分:秒`・`時:分:秒`を入力します。
- **チャプター**: 右クリックのチャプター一覧、`PageUp / PageDown`で移動します。チャプターがない動画は案内を表示します。
- **再生リスト編集**: 再生リスト画面で追加・削除・上下移動・保存・読込ができます。保存形式はUTF-8の`.lumveil.json`で、同じドライブの動画は相対パスを使います。読込で見つからない動画は除外し件数を案内します。再生中の項目を削除すると隣の動画へ進み、リストが空になると停止します。
- **再生情報**: `I` または「その他の操作 → 再生情報 / GPU使用状態」で、実際のGPU／CPUデコード、解像度、フレームレート、ドロップ数などを確認できます。GPU支援の設定値と実際の状態を別々に表示します。
- **状態表示**: 操作バーにリピート・ミュート・AUTO解析中／強度を表示します。
- **操作案内**: `F1`でショートカット一覧を開きます。`Ctrl+O`でも動画を開けます。全画面中も動画面の右クリックメニューを利用できます。
- **失敗時の案内**: 破損動画・見つからないファイル・設定保存失敗を画面に表示します。想定外のGPU設定値は安全な既定値へ戻します。
- **更新の保護**: インストーラーは起動中のLumveilを検出すると中断します。更新ファイルを別フォルダに準備し、旧版はインストール先に隣接する`.previous-...`フォルダへ保持します。切替失敗時は旧版へ戻し、復元できなかった場合はバックアップ場所を案内します。アプリ内更新は終了後にインストーラーを起動します。

## 設定画面（🎛 設定）

ver.1.7では暗闇補正をシャドウリフト方式に刷新しました。設定はアプリ終了後も保存されます。内容が長いタブはスクロールして操作できます。

### かんたん

- **用途別プリセット**: 「軽快」はAnime4Kと通常フレーム補間を停止して負荷を抑えます。「標準」は普段使い向けの画質と軽快さのバランス設定です。「アニメ高画質」はAnime4KモードAとデバンディングを適用します。「暗所優先」はAUTOの選択モードを標準にしますが、動画を開くまでAUTOを自動開始しません。プリセット対象を手動変更すると表示は「カスタム」に戻ります。
- **暗闇補正（自動、⚡ AUTO）**: 暗いシーンを検出して暗部だけを持ち上げるシャドウリフトを主体に補正（コントラスト・彩度は控えめな補助）。「OFF／控えめ／標準／見やすさ優先／極暗」から強さを選べます。

### 画質を調整
明るさ・色味・字幕と音声の見た目を調整します。

- **暗闇補正の詳細**: 発火の敏感さと、AUTOを使わない場合のシャドウリフトを調整できます。
- **シャドウリフト（手動）**: AUTOを使わずに暗部の持ち上げ量を直接指定したいときのスライダー（AUTO停止中のみ操作可）
- **手動画像調整**: 輝度・実効コントラスト（-100〜+300）・ガンマ・彩度・色相を個別設定。実効コントラストの+100まではMPV標準処理、以降は明るさ方向を引き継ぐ拡張シェーダーで補います。映像モード（標準・シネマ・ダイナミック・鮮やか）のプリセットもここから

### 再生と字幕

- **再生終了・再開・並び順**: 再生終了時の動作、前回位置からの再開、フォルダ末尾の動作、次の動画の並びを設定します。
- **字幕・音声の同期調整**: 字幕遅延（±5秒）・字幕サイズ（0.5〜2.0倍）・音声遅延（±5秒）

### 詳細 → なめらかさ
- **フレーム補間**: 中間フレームを生成して映像をなめらかにする（デフォルトON）
- **AMD AMF補間**: AMD GPU専用の動き補償型フレーム補間（前述）。フレーム補間とは同時使用不可（排他制御）

### 詳細 → GPU再生支援
GPUでデコードしCPU負荷を軽減する設定です。

| 選択肢 | 内容 |
|------|------|
| オン（推奨） | 実績のあるデコーダのみ使用 |
| オン（強制・実験的） | 対応していれば全て試行（不安定な場合あり） |
| オフ（CPUで処理） | ソフトウェアデコード。初期状態はこちら |

※ AMD AMF補間を使うには「オン」が必須です。

### 詳細 → シェーダー
- **Anime4Kプリセット**: 公式推奨の組み合わせをワンクリック適用（後述）
- **スケール**: 映像拡大アルゴリズム。Lanczos推奨
- **クロマスケール**: 色差成分の補間アルゴリズム。Spline36推奨
- **デバンディング**: バンディング（縞模様）除去。アニメや暗部のグラデーションに有効
- **アンチリンギング**: 拡大時の輪郭にじみ抑制
- **シグモイド拡大**: 拡大時のリンギング軽減
- **縮小補正**: 縮小時の暗部潰れ防止
- **GLSLシェーダー**: 外部シェーダーファイルを個別に追加（詳細・手動）

### 詳細 → 映像出力
- **ディザリング**: 表示時の色深度変換で生じるバンディングを軽減（fruit推奨）
- **トーンマッピング**: 本物のHDR素材をSDR向けに変換（通常のSDR動画には無効）
- **デインターレース**: 古いTV放送由来のインターレース素材の横縞ノイズ除去

### 再生タブ
- **再生終了時**: 停止 / 次の動画を再生 / リピート（現在の動画を繰り返す）
- **前回位置から再開**: ON / OFF
- **フォルダ末尾**: 停止 / 先頭へ戻る
- **次の動画の並び**: ファイル名順 / 更新日時順

初期値はいずれも従来通りの挙動です。

### 詳細 → 操作バー
常時表示するボタンのON/OFF・並び替え（前述）に加えて、スクリーンショットの保存先フォルダをフルパス表示で変更できます。

## Anime4K GLSLシェーダー

`shaders\` フォルダにAnime4K（MIT License）のシェーダーが同梱されています。
アニメ動画の画質向上に効果的です。

### 適用方法（プリセット・推奨）

`設定` → 詳細 → シェーダー → Anime4Kプリセット から選ぶだけで、公式推奨の組み合わせが一括適用されます。

| プリセット | 用途 |
|-----------|------|
| なし | Anime4K系シェーダーを使わない |
| モードA | 迷ったらコレ（一般的なアニメ向け） |
| モードB | 元からぼやけている映像向け |
| モードC | 劣化が少ないきれいな映像・イラスト向け |
| 軽量 | PCが重いとき用（クリーンアップは省略） |

各ボタンはホバーで詳細説明が出ます。

### 個別に選びたい場合

「GLSLシェーダー（詳細・手動）」の `＋ 追加` から `shaders\` フォルダ内の任意のファイルを組み合わせられます。S / M / L / VL / UL の順に品質・GPU負荷が上がります。

> 実写動画にはAnime4Kは不向きです。シェーダータブの「全クリア」で無効化できます。
