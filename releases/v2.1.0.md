# Lumveil v2.1.0

Windows版Lumveilの安定性と操作性を改善しました。

## 主な変更

- 再生終了時の「リピート」を追加。現在の動画を先頭から繰り返し再生できます。
- AUTO補正・サムネイル生成・動画切替の非同期処理を改善。古い処理結果が別の動画に反映される問題を防ぎ、重複処理・不要な更新を抑制しました。
- 設定が壊れている場合の読み込みを改善し、設定保存に失敗しても終了できるようにしました。
- 設定タブと多数のブックマークをスクロールできるようにし、スライダーと実際の画質・字幕設定の同期を修正しました。
- 全画面中の右クリックメニュー、ポップアップ上のホイール操作、日本語のショートカット案内を改善しました。
- 指定時刻・チャプターへの移動と、編集・保存・読み込みできる再生リストを追加しました。
- 起動時の手動画質復元を切り替えられるようにし、リピート・ミュートなどの再生状態と実際のGPU復号状況を確認できるようにしました。
- 破損動画の再生エラーを表示し、GPU設定の不正な値を既定値へ戻すようにしました。
- インストーラーは起動中のアプリを検出して中断し、更新時に旧版を保持します。切替失敗時の復元も改善しました。
- アンインストール時に、このインストール先を指す現在のユーザーの関連付けを解除します。他アプリの設定は保持し、解除失敗時はファイル削除を中断します。

## ダウンロード

Windows 10 / 11（64bit）向けです。添付の `Lumveil_v2.1.0_Setup.exe` を実行してください。更新前にLumveilを終了してください。

`SHA256SUMS.txt` にインストーラーのSHA-256を掲載しています。

## 検証と対応範囲

51件の単体・回帰テスト、実UI・CPU再生12項目、壊れた設定および保存失敗時の終了確認を実施しています。短時間のGPU描画・補正・リピートとEXEの通常終了も確認しています。

HDR対応の追加はありません。長時間再生・4K動画・実際のインストール環境での更新とアンインストールは今回の検証範囲外です。
